# Backend Project 1: REST API Fundamentals

## 📌 Overview
This project is part of my **Full Stack Development Internship** at **Decode Labs**. It focuses on building the foundational skills of backend development — creating a stateless web server, defining routes, and serving structured JSON data.

## 🎯 Goal
Build a stateless web server using **Node.js** and **Express.js** that:
- Creates a local server
- Defines GET and POST routes
- Returns structured JSON data

## 🛠️ Tech Stack
- **Node.js** — JavaScript runtime
- **Express.js** — Web framework for routing and server logic

## 🚀 Features
- `GET /` — Returns a welcome/status message
- `GET /users` — Returns a list of users in JSON format
- `POST /users` — Accepts a new user object and returns a success response

## ⚙️ How to Run Locally

1. Clone this repository
```bash
git clone https://github.com/fizzafatima777/backend-project-rest-api.git
```

2. Navigate into the project folder
```bash
cd backend-project-rest-api
```

3. Install dependencies
```bash
npm install
```

4. Start the server
```bash
node server.js
```

5. Open your browser and visit:
```
http://localhost:8000
```

## 📂 API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/` | Health check / welcome message |
| GET | `/users` | Fetch list of users |
| POST | `/users` | Create a new user |

## 📖 Key Concepts Learned
- HTTP Methods (GET, POST) and their use cases
- Statelessness in REST APIs
- JSON serialization for data transport
- HTTP status codes (200, 201, 400, 404, 500)
- Routing logic using Express.js
